# 古文単語 学習アプリ

古文単語を「覚える → 意味を確かめる → 文中で解く」の順に学ぶ静的Webアプリです。

公開版: https://shtomi-tech.github.io/kobun-vocab-learning/

## 起動

```powershell
cd C:\Users\shtom\dev\kobun-vocab-learning
py -3 -m http.server 8062 --bind 127.0.0.1
```

`http://127.0.0.1:8062/` を開きます。JSONを読み込むため、`index.html` の直接表示は使いません。

## 現在の学習フロー

1. 4語の暗記カードを読む
2. その4語について、語から意味を選ぶ
3. この「覚える → 確かめる」を3ブロック行う
4. 意味確認で誤答した語をカードで確認する
5. 現代語訳を手掛かりに、例文の空欄へ入る語の基本形を選ぶ
6. 文中問題の誤答を解き直す
7. 全12語の最終チェックで80%以上を取る

進捗と途中位置はブラウザのローカルストレージに保存します。

暗記カード画面では「意味を隠して覚える」を任意でオンにできます。見出し語と例文だけを見て意味を思い出してから、「意味を見る」ボタンで意味・例文の訳を表示します。既定はオフで、この設定はページを開いている間だけ有効です（保存はされません）。

## 補助学習

- 全セットの通常学習で文中問題まで回答した語を、共通プールとして「意味だけ復習」の対象にします。
- 1回の出題は最大20語です。
- 正解した語は1日・3日・7日・14日後へ順に回し、誤答すると「要再確認」に戻します。
- 通常学習・意味だけ復習・誤答確認・最終チェックの履歴を、セットごとに最大500件保存します。
- 学習中はセットごとに途中位置を保存し、ホームから再開できます。
- ホームのセット選択を開くと、切り替える前に各セットの状態（未着手・学習中・要復習・最終チェック待ち・CLEAR）、文中回答済み数、要復習数、最終チェックBESTを確認できます。

## データ

- `data/manifest.json`: セット一覧
- `data/set-01.json`: 第1セット「基本語彙」12語
- `data/set-02.json`: 第2セット「ことば・人間関係」12語
- `data/set-03.json`: 第3セット「世・心情・出家」12語
- `data/set-04.json`: 第4セット「死・宿命・皇室敬語」12語
- `data/set-05.json`: 第5セット「敬語・茫然・強調表現」12語
- `data/set-06.json`: 第6セット「評価・通常・否定表現」12語
- `data/set-07.json`: 第7セット「否定・禁止・副詞表現」12語
- `data/set-08.json`: 第8セット「副詞・尊敬表現」12語
- `data/set-09.json`: 第9セット「尊敬・謙譲表現」12語
- `data/set-10.json`: 第10セット「謙譲表現・敬語の識別」12語
- `data/set-11.json`: 第11セット「皇室・貴族語彙」12語
- `data/set-12.json`: 第12セット「人間関係・人称表現」12語
- `data/set-13.json`: 第13セット「指示代名詞・時間表現」12語

新しいセットは、同じ形式のJSONを追加し、manifestへ登録します。各語には `example`、`translation`、`source`、`cloze` に加え、`notes`（空でない解説・補足の文字列配列。1件以上必須）を必ず収録します。

## 匿名利用・生徒別同期

通常のURLではローカル保存だけで動作します。`?s=<生徒ID>&t=<アクセストークン>`付きURLでは、`static/config.json`にSupabase設定がある場合だけ、共通の`app_students` / `app_progress`へ同期します。アプリIDは`kobun-vocab-learning`です。共有URLで使うと、同じ端末でも生徒IDごとにローカルの一時キャッシュを分離します。

生徒の登録と生徒別URLの発行は、アプリ管理ポータルの生徒共有パネルから行います。GitHub Pages公開版では、ActionsのSecretsからSupabase設定を生成します。

設定例は`static/config.example.json`です。設定がない場合も匿名利用には影響しません。
