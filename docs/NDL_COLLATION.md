## なぜ収録範囲を先に見るのか

生成された出典表記の誤りは、本文の字面より先に**収録範囲**で露見する。作品名・段番号・頁がもっともらしく揃っていても、その底本にその作品がその頁で入っていなければ、本文を1文字も読まずに誤りと確定できる。

`https://dl.ndl.go.jp/api/iiif/<PID>/manifest.json` の `structures` に、収録作品と開始ページが入っている。`label` が「竹取物語/1」の形で、`/` の後ろが**開始ページ番号**、`canvases[0]` の末尾が**コマ番号**。1コマ＝見開き2ページなので、両者は一致しない。

`metadata` の `Access Restrictions` が `PDM`（保護期間満了）でなければ底本にしない。書名だけで判断して現代語訳や解説巻を底本にした事例が過去にある。

## 全文検索の癖

`https://lab.ndl.go.jp/dl/api/book/search?keyword=...&size=N`

- **書名やPIDで絞る手段が無い。** `id` / `bibId` パラメータは効かない。関連度順に返るだけなので、頻出語は他書に押し出される。`size=200` にしても変わらないことがある。
- 対策は**固有性の高い連語**で引くこと。「なんでふ」では当たらないが「その枝扇」なら一発で当たる。**旧字体で入力する**（「龜山殿」「兒」「拔く」）。
- `highlights` は**底本の字面そのもの**。ここから本文を起こしてよい。踊り字（ゝ ゞ 〳〵）と一部の異体字は `〓` に化けるので、その語が本文の要になるときだけ版面で確かめる。
- `page` フィールドは**総コマ数**であってヒット位置ではない。所在は `structures` の頁範囲と突き合わせて絞る。
- 索引対象は一部の資料だけ。**木版本・変体仮名の資料は索引されない**ので、当たらなくても「本文が無い」証拠にはならない。この場合は版面を読むしかない。
- 引用の前後が欲しいときは、`highlights` がキーワードの位置から始まる性質を使う。**欲しい箇所より前の連語で引き直す**と、その後ろが返ってくる。

## 版面を読む

```
https://dl.ndl.go.jp/api/iiif/<PID>/R<7桁canvas>/<region>/2000,/0/default.jpg
```

- `region` は `full` か `x,y,w,h`。原寸は manifest の `width` / `height`（例 3800×2964）。
- 1コマ＝見開き2ページ。縦組みは右から左へ読むので、**右頁が若い番号、左頁がその次**（1172432 の canvas 179 は右 346・左 347）。柱（ページ番号）は各頁の外側の端にある。
- 見開き全体を 2000px 幅で取ると活字はぎりぎり読める。**特定の柱だけを詰めて読むときは `region` で切り出す**と精度が上がる。目的の頁が見開きのどちら側かを見てから、その半分をさらに列単位で切る。
- 開始コマの見当は `structures` から。ページ番号 P に対応するコマは、その作品の開始コマ + (P − 開始ページ) / 2 で概算できる。ずれるので前後1コマを見る。
- 頭注付きの活字本（有朋堂文庫など）は、各コマ上部15〜25%だけを切り出して数コマ分を縦に連結すると、1回のReadで十数ページ分の頭注＝内容要約を読める。目的の場面を絞ってから全ページを開く。

## 使ってはいけない資料

`docs/SOURCE_EDITIONS.md` に「確認メモ」として除外理由が残っている。同じ資料を再検討して時間を使わないよう、採用前にそこを見る。

**源氏物語は底本を特定しない**という例外が確立している。大島本系の校訂本文とNDL公開の活字翻刻（流布本系）で本文が一致しないため。`source` には作品名と帖名だけを書き、`SOURCE_EDITIONS.md` の底本欄は「—（底本を特定しない）」とする。**この例外を他の作品に広げない。**

日文研の和歌データベースは編集著作物として権利を主張しているため、**所在確認にだけ使い、本文の転記元にしない**。
