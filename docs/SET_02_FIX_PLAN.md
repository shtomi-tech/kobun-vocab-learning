## 監査方針

- 添付資料は現在の環境から参照できないため、添付資料由来とは扱わない。

- 源氏物語は既存方針に従い、本文が見つかっても特定のNDL資料を底本として掲げない。
- 例文を更新するときは、現代語訳と `cloze` を同時に見直す。
