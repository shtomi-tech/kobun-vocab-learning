## 監査方針

- 添付資料は現在の環境から参照できないため、添付資料由来とは扱わない。
- 和歌は本文、五句、読み、作者、歌集・巻・歌番号を確認する。
- 散文は本文の採用箇所と底本を確認できたものだけ更新する。源氏物語は既存方針に従い、底本を特定しない。
- 例文を更新するときは、現代語訳と `cloze` を同時に見直す。

## 変更方針

1. `kv03-026`・`kv03-034`は、既存の和歌入力表と本文・作者・歌番号の対応を維持する。
2. `kv03-031`は詞書を和歌本文と混同せず、`exampleForm: "prose"` を維持する。
3. 源氏物語の3語は、本文を確認しても特定のNDL資料を底本として追加しない。
4. 採用箇所を確認できない散文は、出典を推測で補わず現行データを維持する。
