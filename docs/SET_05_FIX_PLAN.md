## 調査結果

- `kv05-054`: 『大鏡』「内大臣道隆」の本文に「ものもおぼえず、御裝束もひきみだりて、車さしよせつゝ、人にかられてのり給ふをぞ」とある。NDL PID 1176915はPDMで、ページ内検索の該当コマはp.216。版面画像で本文を照合した。
- `kv05-060`: 『徒然草』第44段に「笛をえならず吹きすさびたる」とある。NDL PID 1172432はPDMで、該当箇所はp.341。版面画像で本文を照合した。
- `kv05-052`: NDL PID 1026603『宇津保物語.下』に「われか人かとのみある」の用例はあるが、見出し語の「われ（かひとか）にもあらず」と語形が一致せず、容貌を評する文脈でもあるため採用しない。
- `kv05-058`: 「〇〇といふも世の常なり」は空欄前の語を差し替えるテンプレートであり、特定作品の本文へ置き換えると学習対象の句型が変わるため採用しない。

## 採用

### kv05-054 ものもおぼえず

> ものもおぼえず、御装束もひきみだりて、車さしよせつつ、人にかられてのり給ふをぞ、…

- 現代語訳: 何もわからず、装束も乱して、車を近づけさせ、人に助けられてお乗りになるのを、…
- 出典: `大鏡（内大臣道隆）`
- 空欄: `ものもおぼえず` を文頭で隠す。

### kv05-060 えならず

> あやしの竹のあみ戸の内より、いと若き男の、月影に色あひさだかならねど、つややかなる狩衣に濃き指貫、いとゆゑづきたるさまにて、ささやかなる童ひとりを具して、遥かなる田の中の細道を、稲葉の露にそぼちつつ分け行くほど、笛をえならず吹きすさびたる、…

- 現代語訳: 粗末な竹の編み戸の中から、たいそう若い男が、月の光で色合いははっきりしないけれど、つややかな狩衣に濃い指貫を身につけ、由緒ありげな様子で小さな童を一人連れ、遠い田の中の細道を稲葉の露に濡れながら分けて行くとき、笛をこの上なく見事に吹き興じているのは、…
- 出典: `徒然草（第44段）`
- 空欄: `えならず` を隠す。
