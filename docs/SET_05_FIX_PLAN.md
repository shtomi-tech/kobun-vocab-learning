## 採用

### kv05-052 われ（かひとか）にもあらず

> おとゞ心惑ひて、われか人かにもあらでの給ふ。

- 現代語訳: 大殿は心が乱れて、我を忘れたようになっておっしゃる。
- 出典: `宇津保物語（藤原の君）`
- 空欄: `われかひとか` を隠す。底本の「人」は、見出し語の読みを示すため学習画面ではかなにした。

### kv05-054 ものもおぼえず

> ものもおぼえず、御装束もひきみだりて、車さしよせつつ、人にかられてのり給ふをぞ、…

- 現代語訳: 何もわからず、装束も乱して、車を近づけさせ、人に助けられてお乗りになるのを、…
- 出典: `大鏡（内大臣道隆）`
- 空欄: `ものもおぼえず` を文頭で隠す。

### kv05-060 えならず

> あやしの竹のあみ戸の内より、いと若き男の、月影に色あひさだかならねど、つややかなる狩衣に濃き指貫、いとゆゑづきたるさまにて、ささやかなる童ひとりを具して、遥かなる田の中の細道を、稲葉の露にそぼちつつ分け行くほど、笛をえならず吹きすさびたる、…

- 現代語訳: 粗末な竹の編み戸の中から、たいそう若い男が、月の光で色合いははっきりしないけれど、つややかな狩衣に濃い指貫を身につけ、由緒ありげな様子で小さな童を一人連れ、遠い田の中の細道を稲葉の露に濡れながら分けて行くとき、笛をこの上なく見事に吹き興じているのは、…
- 出典: `徒然草（第44段）`
- 空欄: `えならず` を隠す。

### kv05-058 〇〇といふも世の常なり

> 高遠の大貳、御笛の師にて物し給ふを、異笛ふたつして、高砂ををりかへし吹かせ給へば、猶いみじうめでたしといふもよのつねなり。

- 現代語訳: 高遠の大弐を笛の師として、別の笛を二つ使って「高砂」を繰り返し吹かせなさると、「たいそうすばらしい」と言うだけではありきたりなくらいである。
- 出典: `枕草子（第230段）`
- 空欄: 本文の「めでたし」を隠す。底本の「よのつね」は、学習画面では「世の常」とした。
