## 監査方針

- 添付資料は現在の環境から参照できないため、添付資料由来とは扱わない。

- 例文を更新するときは、現代語訳と `cloze` を同時に見直す。

## 変更方針

1. `kv06-070`・`kv06-071`は、確認したPDM資料の本文に合わせる。
2. 踊り字・旧字体・送り仮名は、意味と語形を損なわない範囲で既存データの表記方針に合わせる。
3. 源氏物語の2語は、本文を確認しても特定のNDL資料を底本として追加しない。
4. 採用箇所を確認できない語は、出典を推測で補わず現行データを維持する。
