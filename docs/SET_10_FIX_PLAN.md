## 監査方針

- 添付資料は現在の環境から参照できないため、添付資料由来とは扱わない。
- 和歌は本文、五句、読み、作者、歌集・巻・歌番号を確認する。
- 散文はNDLのPDM資料で全文検索と版面を照合できたものだけ、採用箇所を出典台帳へ記録する。
- 源氏物語は既存方針に従い、本文が見つかっても特定のNDL資料を底本として掲げない。

## 変更方針

1. `kv10-110`・`kv10-111`・`kv10-112`は『竹取物語・大和物語・住吉物語・唐物語』（PID 1109906）の版面で確認した本文範囲を出典に反映する。
2. `kv10-115`・`kv10-117`は『伊勢物語』（PID 1109206）の版面で確認した本文範囲を出典に反映する。
3. `kv10-118`は『枕草紙・方丈記・徒然草』（PID 1172432）の徒然草本文で確認した範囲を出典に反映する。
4. `kv10-116`は既存の和歌入力表と本文・作者・歌番号の対応を維持する。
5. 採用箇所を確認できない語は、出典を推測で補わず現行データを維持する。
6. `kv10-109`は『伊勢物語』（PID 1109206）の武蔵鐙本文で確認したため、出典に帖名を加える。
7. `kv10-113`・`kv10-114`は『国文大観.1 物語部1 源氏物語上』（PID 991353）で採用箇所を確認し、出典に帖名だけを加える。特定資料を源氏物語の固定底本にはしない。
8. `kv10-119`は『群書類従.第六輯』（PID 1879486）の毎月抄本文で確認し、現行の学習用表記を維持する。
