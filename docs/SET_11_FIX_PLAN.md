## 監査方針

- 添付資料は現在の環境から参照できないため、添付資料由来とは扱わない。

## 変更方針

1. `kv11-122`・`kv11-124`は『有朋堂文庫.〔第65〕』（PID 1913578）の版面で確認した本文範囲を出典に反映する。

3. `kv11-126`は『大鏡』（PID 1176915）、`kv11-128`は『伊勢物語』（PID 1109206）の版面で確認した範囲を出典に反映する。
4. `kv11-131`は『宇津保物語.上』（PID 1018114）の版面で確認した本文へ更新する。
5. `kv11-129`の既存出典は維持する。
6. 源氏物語の語は、本文を確認しても特定のNDL資料を底本として追加しない。
7. 採用箇所を確認できない語は、出典を推測で補わず現行データを維持する。
