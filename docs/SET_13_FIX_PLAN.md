## 変更方針

1. `kv13-145`・`kv13-148`・`kv13-149`・`kv13-147`・`kv13-152`・`kv13-156`は、確認したPDM資料の本文範囲を出典に反映する。
2. 現行例文が本文の読み・漢字・句読点を学習用に整理したものは、意味を変えない範囲で維持する。
3. 源氏物語の6語は、本文を確認しても特定のNDL資料を底本として追加しない。
4. 採用箇所を確認できない語は、出典を推測で補わず現行データを維持する。
5. 源氏物語の6語は、確認できた帖名だけを `source` に反映し、本文・訳・空欄は学習画面向けの表記を維持する。
