## 1. 修正項目

### 1-1. 歴史的仮名遣いの誤り（優先度: 高／単独で修正可）

- 対象: `data/set-14.json` の `kv14-160`
  - `headword`: `ゆくすえ` → `ゆくすゑ`
  - `example`: `ゆくすえを思ひて、日々を慎む。` → `ゆくすゑを思ひて、日々を慎む。`
  - `cloze`: 同様に `ゆくすゑ` を空欄化した形へ
- 対象: `data/set-14.json` の `kv14-159`
  - `example`: `こしかたを思ひ、ゆくすえを案ずる。` → `…ゆくすゑを案ずる。`
  - `cloze`: 空欄は `こしかた` のままだが、後続文字列が変わるため追随して更新する
- 根拠: 本リポジトリは歴史的仮名遣いを採用しており、`data/set-02.json` に見出し語「もとすゑ」・例文「歌のもとすゑ問ひたるに」の先例がある。
- 注意: `translation` は現代語訳なので変更しない。

### 1-2. 文脈クイズで正解が一意に定まらない（優先度: 高）

**現象**: 「空欄に入る語の基本形は？」の選択肢は同一セット内の見出し語からランダムに選ばれ、意味重複フィルタが効かない。set-14 には `meanings` が文字列レベルで完全一致する語が同居しているため、正解が複数成立する設問が生成される。

| クラスタ | 語 | 状態 |
|---|---|---|
| まめ系 | まめなり／まめまめし／まめやかなり | 3語の `meanings` が完全一致 |
| あだ系 | あだなり／あだあだし | 2語の `meanings` が完全一致 |
| あて系 | あてなり／あてはかなり | 2語の `meanings` が完全一致 |

実例:
- 「この道具、（　）。」現代語訳「この道具は、実用的で本格的だ。」→ 正解 `まめまめし` だが `まめなり`・`まめやかなり` も成立
- 「その姫君、（　）。」→ `あてなり` と `あてはかなり` が区別不能
- 「その男の心、（　）。」→ `あだなり` と `あだあだし` が区別不能

**原因箇所**: `static/mode-vocab.js:246` の `distinctCandidates`。`kind !== "meaning"` が真になるため、文脈クイズ（`kind === "context"`）では `hasMeaningOverlap` / `hasMeaningFamilyOverlap` による除外が素通りする。意味クイズ側（`meaningChoicesAreSafe`、`static/mode-vocab.js:269`）には同等の保護がある。

**A-1（アプリ側・推奨）**:
- `choiceSet` の `distinctCandidates` から `kind !== "meaning"` の短絡を外し、文脈クイズでも意味重複した見出し語を誤答候補から除外する。`addCandidates` 内の同条件も併せて見直す。
- 影響確認: set-14 は12語中、最大クラスタを除いても9語残るため誤答3件の確保は可能。全14セットで「誤答候補が3件に満たないケース」が出ないことを確認する（不足時のフォールバックが意味クイズにしかない点に注意）。
- 既存セットへの副作用（従来出ていた誤答が出なくなる）は、正解が一意になる方向の変化なので許容する。

**A-2（データ側・併用）**:
- 各語の `example` / `translation` を、その語でなければ成立しない文脈へ書き直す。方向性:
  - `まめなり` … 人の性質としての「誠実・まじめ」
  - `まめまめし` … 物・道具の「実用的・本格的」（`translation` に「実用」を明示）
  - `まめやかなり` … 心のこもった「本気・真剣」（`translation` に「本気」を明示）
  - `あだなり` … 恋愛文脈の「浮気・不誠実」
  - `あだあだし` … 言葉・約束の「うわついた・実がない」
  - `あてなり` … 身分の「高貴」
  - `あてはかなり` … 姿・物腰の「上品・優美」
- `meanings` 配列自体の共通化は語義として妥当なので、原則そのまま残す（訳文側で弁別する）。

### 1-3. 例文の出典（優先度: 中／論点B次第）

- 初期計画時点では12語すべてを学習用例文として扱っていた。現在は4語をPDM本文へ更新し、7語はPDM本文で採用箇所を確認して源氏物語の帖名を具体化した。`kv14-159` は既存の和歌出典を維持している。
- B-1 を採る場合: 各語の用例を古典作品から採り、`source` を作品名にする。出典が確定できない語は `出典未詳`（既存11件の先例あり）または `学習用例文` を維持し、どの語を維持したか報告に明記する。
- 差し替え時は `cloze` が `example` の連続一部分を置換する制約（`scripts/check-data.mjs`）と、空欄が付属語を含まない制約を満たすこと。

### 1-4. 軽微な整備（優先度: 低）

- `kv14-168 ただなり` の `kanji`「徒なり・只なり」は、同一セットの `kv14-161 あだなり`「徒なり」と表記が衝突する。「只なり・直なり」を先頭に置く案を検討する。
- `kv14-167 あてはかなり` は『源氏物語』等に用例があるが入試頻出度は低い。意図的な収録なら維持、そうでなければ差し替え候補。

## 2. 実施順序

1. 1-1（仮名遣い）— 単独で完結。まず適用する。
2. 論点 A・B をユーザーが決定。
