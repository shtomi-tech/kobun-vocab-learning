### 1-1. 意味記述で直す点

- **kv16-188「さらぬ」**: 提供ポイントは「そうではない」と「避けることができない」を1語に同居させている。後者は「避（さ）らぬ」（別語）で、既存の `kv04-042 さらぬわかれ【避らぬ別れ】＝死別` がそれにあたる。**`meanings` は「そうではない・それ以外の」に一本化**し、「避らぬ（避けられない）」は同音別語として `notes` で `kv04-042` と対比させる。「大したことのない」は用例が限定的なので `meanings` から落とす（家族ガード `/たいした|これといった.../` に当たり、誤答候補を狭めるだけの副作用がある）。
- **kv16-184**: 提供訳「そのまま生きているわけにはいかない」は例文（とはずがたり）固有の含意。**語義は「そのままではいられない・そのまま放置できない」**とし、生死の含みは例文の `translation` 側で処理する。
- **kv16-181 と kv16-192 は `meanings` が完全一致**になる。既存の `kv14-163 あだなり` / `kv14-164 あだあだし` と同じ形で、選択肢生成側は同一意味テキストを候補から除外するため問題は起きない（`check-context-choices.mjs` で確認）。

## 3. 例文・空欄の設計

### 3-1. `cloze` 案と検査上の当たり

| ID | 空欄になる語形 | 検査上の注意 |
|---|---|---|
| kv16-181 | さ | **1文字空欄は答え露出の自動検査対象外**。例文中に他の「さ」が無いか人手で見る（提供例文はOK） |
| kv16-182 | さて | 末尾「て」は `attachedSuffixes` に当たるが、見出し語と完全一致するため通る |
| kv16-183 | さてありぬべし | 見出し語の括弧内「しも」が例文に無い形。末尾「べし」は付属語リストに無く通る |
| kv16-184 | さてしもあら**ね** | 已然形。末尾「ね」は付属語リストに無い。接続助詞「ば」は空欄に含めない |
| kv16-185 | さる | 例文の「さらに」は「さる」を含まないので露出なし |
| kv16-186 | さるは | — |
| kv16-187 | さるものにて | 末尾「て」は見出し語と完全一致で通る |
| kv16-188 | さらぬ | — |
| kv16-189 | さるべき | 末尾「べき」は見出し語と完全一致で通る |
| kv16-190/191 | さればよ / さればこそ | 「されば」だけを空欄にしない（別語になる） |
| kv16-192 | しか | 1文字空欄。人手確認 |

`（　）` はちょうど1つ、`example` の連続1スパン。空欄の前後は `example` と完全一致させる。

### 3-2. 分割に伴う kv16-190「さればよ」の例文（決定Aの帰結）

191 と同じ竹取物語の一節は使えない（同一 `example` は学習上も検査上も意味がない）。「さればよ」の独立用例を、既に底本のある作品から探す。**探索順**: 源氏物語 → 枕草子 → 伊勢物語 → 竹取物語。見つからなければ §2-1 の手順で `学習用作例` として作例化する。

**190 と 191 は `meanings` が完全一致**するため、2語を区別する手掛かりは語形（末尾「よ」／「こそ」）だけになる。次の2点で支える。

- `notes` に、末尾の違いが何を担うかを1行ずつ書く（「よ」は詠嘆の終助詞で言い切り、「こそ」は係助詞で下に已然形を伴う／言いさす形）。カード上ではここが唯一の識別情報になる。
- 文中問題では**空欄の直後を残す**。「こそ」の係り結びが見える位置に空欄を置けば、両者は文法的に弁別できる。空欄が文末で切れる形は避ける。
- 選択肢生成側は同一意味テキストの語を候補から除外するため、190と191が互いの誤答に並ぶことはない（`check-context-choices.mjs` で確認）。

### 3-3. 文脈の手掛かり（§6）

- **kv16-182「さて、年ごろ経にけるに…」は空欄の前が無く、後続も情報が薄い。**「さ」「さる」でも文法的に置けてしまうため、前文脈を含む形に例文を伸ばすか、別の用例に差し替える。
- kv16-181・192 も同様に短い。前後を数語伸ばして、指示内容が分かる形にする。
- 12語のうち9語が「さ＋α」で、語形が近い。文中問題では**語形の切れ目**が唯一の手掛かりになる箇所が出るので、空欄前後に活用語尾・接続を残す。

## 4. `notes` の方針

- 提供の「ポイント」を、**学習者向けの解説文**に書き直して `notes` に入れる（1件以上、空文字不可）。
- **作業メモ・編集判断を書かない。** `notes` は暗記カードの「解説・補足」としてそのまま表示される（SET_15 の修正項目 1-1 と同じ失敗を繰り返さない）。
- 語の分解説明（「さ＋て」「さ＋ある」）は、この12語の中核なので各語に1行入れる。
- 既存語との対比を入れる語:
  - kv16-188 ↔ `kv04-042 さらぬわかれ`（同音別語「避らぬ」）
  - kv16-189 ↔ `kv04-045 さるべきにや（ありけむ）`（「さるべき」を含む定型句）
  - kv16-181/192 ↔ `kv07-078 さらに〜打消`（「さ」系だが呼応の副詞）

## 6. 検証

```bash
node --check static/mode-vocab.js

node scripts/check-waka-choices.mjs
node scripts/check-waka-display.mjs
```

- `check-context-choices.mjs` は**全セット横断**で「相互に安全な誤答候補が3つ以上あるか」を見る。12語中9語が「そのように」系の意味を持つため、**このセットの追加で既存語の候補が枯れる可能性がある**。落ちた場合は `meanings` の文言（「そのように」の重複表現）を調整する。
- 人手確認（§7「人手で守ること」）: 本文が底本と一致、`translation` と `meanings` の噛み合い、1文字空欄（kv16-181・192）の答え露出。
- 実ブラウザ確認は、データ追加のみでUI変更が無いため、**セット選択に第16セットが出る／暗記カードと文中問題が表示される／コンソールエラーが無い**の3点に限る（ユーザーの最小検証方針に従う）。
