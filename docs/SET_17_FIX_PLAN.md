## 1. 修正項目

### 1-1. 文脈四択の正答が一意に決まらない（優先度: 最高）

#### 問題

12語中7語（いかに・いかが・いかで・なに・なぞ・など（て）・な（ん）でふ）がほぼ同義の疑問・反語副詞。AUTHORING_STANDARD §6「同一セット内に意味の近い語を集めすぎない」に反する。

文脈問題の誤答は `static/mode-vocab.js` の `choiceSet()` が**同一セット内**から選ぶ（`state.set.words`）。意味重複ガード `isMeaningSafePair()` を再現したところ、次のペアが「同時に選択肢へ出せる」と判定された。

| 出題語（cloze） | 同時に出うる誤答 | 誤答を入れた結果 |
|---|---|---|
| なぞ「（　）かくは嘆きたまふ」 | など（て）／な（ん）でふ | 「などかくは嘆きたまふ」＝**完全に成立** |
| など（て）「（　）かく心細くおぼゆらむ」 | なぞ | 「なぞかく心細くおぼゆらむ」＝**完全に成立** |
| いかに「親は（　）嘆き給ふらむ」 | いかで | 「親はいかで嘆き給ふらむ」＝成立 |
| いかで「（　）この児を見むと思ふ」 | いかに／なぞ | いずれも成立 |
| いかが「「この事（　）思す」」 | なぞ／なに | 成立 |

とくに `kv17-202` と `kv17-203` は cloze の構文までほぼ同型（「（　）＋かく＋〜」）で、互いの答えがそのまま入る。

#### 原因

意味文字列の正規化 `normalizeMeaning()` が**丸数字 `①②③` を除去しない**。そのため

- なぞ: `"なぜ・どうして〜か、いや〜ない"` → `なぜどうしてかいやない`
- など（て）: `"②どうして〜か、いや〜ない"` → `②どうしてかいやない`

が別文字列と判定され、既存の部分一致ガード（4文字以上の包含）をすり抜ける。丸数字を除去すれば `なぜどうしてかいやない` が `どうしてかいやない` を包含し、ガードが働く。

#### 修正

**(a) 正規化に丸数字を追加**（`static/mode-vocab.js` と `scripts/check-context-choices.mjs` の両方。同じ式を2箇所に持っているので必ず揃える）

```
[「」『』【】（）()、。・／〜～⇔\s]  →  [「」『』【】（）()、。・／〜～⇔①②③④⑤\s]
```

**(b) `meaningFamilies` に2つ追加**（`static/mode-vocab.js`。`check-context-choices.mjs` は同ファイルから正規表現を読み出すので、追記は1箇所でよい）

```js
/なぜ|どうして|どのように|どんなに|どうにかして|何とかして/,  // 疑問・反語の副詞
/そのように|このように|あのように|そうである|こう$|そう$/,      // 指示副詞
```

#### 検証済みの効果

3案を全17セット・同一セット内プールで比較した（`choiceSet()` の実際の候補範囲を再現）。

| 案 | 第17セットで同時に出うる疑問語ペア | 選択肢が4つ未満になる語（全セット） |
|---|---|---|
| 現状 | なぞ×など、いかで×なぞ、いかに×いかで ほか多数 | 24語（第4・第5セット。**既存の問題**） |
| (a) のみ | いかに×いかで、なぞ×なでふ が残る | 24語（増減なし） |
| **(a)+(b)** | **疑問語どうしはすべて遮断** | **24語（増減なし）** |

(a)+(b) は第17セットの曖昧性を解消しつつ、既存セットの選択肢数を1つも減らさない。第17セットの各語は適用後も相互に安全な誤答候補を5語以上保持する。

#### 残るリスク（データ側で対処。§1-2 へ）

指示語 × 疑問語のペアは (b) 適用後も同時に出る。例えば `kv17-195 かく`「世の人は（　）思へど」に `いかに` を入れると「世の人はいかに思へど」で文法的に成立してしまう。**例文側で、その語でなければ通らない文脈を作る**必要がある。

#### 既存の検査の限界（記録）

`check-context-choices.mjs` は**全セット横断**（`allWords`）で候補を数えるが、実際の文脈問題は**同一セット内**から選ぶ。このズレのため、当時は第4・第5セットの24語が選択肢2〜3個になっていた（`kind === "context"` には他セットへのフォールバックが無い）。その後、セット内検査を追加し、意味ガードの過剰な同一視も分割して解消した。

### 1-2. 12語すべてが「学習用作例」（優先度: 高／決定Bの帰結）

§2-1 は `学習用作例` を「句型の学習用作例」に限定している。第17セットの12語は句型ではない普通の指示語・疑問副詞で、実出典に用例が豊富。リポジトリの履歴自体が `8eb7ddc Replace non-classical examples with sourced texts` と、作例→実出典の方向で進んできた。

| セット | 作例の語数 |
|---|---|
| 第1〜16セット（192語） | 6語（うち4語は句型が集中する第5セット） |
| 第16セット（同じ指示語カテゴリ） | 1語 / 12語 |
| **第17セット** | **12語 / 12語（計画開始時）** |

第16セットの `notes` が「本文では「さてもありぬべし」となっており…」と実本文を参照できているのに対し、第17セットはそれができていない。学習価値の面でも後退している。

**あわせて §1-1 の残存リスクを例文で潰す。** 差し替え後の例文は、空欄前後にその語でなければ通らない手掛かりを残す（§6）。とくに次を守る。

- `kv17-202 なぞ` と `kv17-203 など（て）` の例文を**別構文にする**（現状は「（　）かく〜」で同型）。
- 疑問語の例文には、語義を確定させる呼応を残す（願望の「いかで」なら下に「ばや」「なむ」「む」、程度の「いかに」なら「〜ばかり」「いかに〜らむ」など）。
- 指示語の例文に、同セットの疑問語が入り込める空欄を作らない。

## 2. 出典の確定作業（決定Bを採る場合・作業量の大半）
