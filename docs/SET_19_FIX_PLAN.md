## 実装方針

- 散文9語を `data/set-19.json` へ直接反映する。
- 本文の表記は確認資料の字面を基本とし、句読点は学習画面用に補う。
- 空欄は見出し語またはその活用部分だけを隠し、助動詞・接続助詞を不必要に含めない。
- 新たに使用する底本は `docs/SOURCE_EDITIONS.md` に追加し、語ごとの採用箇所も更新する。
