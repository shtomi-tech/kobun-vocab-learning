# 第20セット 例文見直し計画

## 目的

第20セット（`kv20-229`〜`kv20-240`）の例文を、次の優先順位で見直す。

1. 添付資料の例文
2. 和歌
3. 古典の文章
4. 学習用作例

添付資料は現在のワークスペースから参照できないため、添付資料由来の採用は保留し、NDLデジタルコレクションのインターネット公開資料で本文を確認できた和歌・古典本文を採用する。底本を確認できないものは、実出典を装わず `学習用作例` とする。

## 監査結果

- 第20セットは12語すべてが現状 `学習用作例`。
- `data/manifest.json` のセットID、各語のID、`dataVersion` は変更しない。
- 既存の語義・注記は原則として維持し、例文、現代語訳、出典、穴埋め、例文形式だけを見直す。
- 句読点・旧字体は、既存の学習画面での可読性とプロジェクトの表記方針に合わせて整える。ただし本文の語句は変えない。

- `kv20-232` は源氏物語の語句と段名を確認できるが、採用する本文の底本は特定しない。出典欄には底本名を追加しない。
