## 1. 何が問題か

### 1-1. 源氏物語（17語＋1語に影響）— 底本が現代語訳

`docs/SOURCE_EDITIONS.md` は源氏物語の底本を「『源氏物語』巻1〜22（谷崎潤一郎訳、中央公論社、昭和14-15）」としている。NDLのIIIFマニフェストで確認した内容:

| PID | Creator | Publisher | 年 | コマ数 |
|---|---|---|---|---:|
| 1151640 / 1151664 / 1151693 / 1151715 | **谷崎潤一郎 訳** | 中央公論社 | 昭14至15 | 各67前後 |

『潤一郎訳源氏物語』は現代語訳で、**古文本文を含まない**。したがって `data/set-15.json` と `data/set-16.json` の源氏物語の `example`（古文）は、この資料からは起こせない。底本記載が実態と一致しておらず、§2-2 違反にあたる。

### 1-2. 徒然草（1語）— 底本が変体仮名の古版本

`kv16-187` の底本 PID 2544701 は `Publication Date = [慶長・元和年間]` の古版本。SET_15 の決定A-2 で「版面から起こすのは現実的でない」として活字翻刻へ切り替えた方針と矛盾する。実装済みの本文は校訂本文の字面であり、この版本から起こしたとは考えにくい。

### 1-3. 枕草子（1語）— 底本が影印と見られる

`kv15-170` の底本 PID 3439333 は『枕草子』育徳財団・昭和2・**84コマ**。枕草子全文を収めるには少なすぎ、前田家本の複製（影印）と見られる。Cで同時に差し替える。

## 4. 本文の照合手順

1. §3 の開始コマから、その帖の本文を追って該当箇所を探す。画像は次のURLで取得できる（`R` の後は7桁ゼロ埋め）。

   ```
   https://dl.ndl.go.jp/api/iiif/1085953/R0000122/full/full/0/default.jpg
   ```

2. 探索の当たりを付けるには、次世代デジタルライブラリーの全文検索APIが使える。OCRなので字面の確定には使わず、**所在確認と異同の見当付けにだけ**用いる（日文研和歌DBと同じ扱い）。

   ```bash
   curl -s -G --data-urlencode "keyword=春のけしきにこそあめれ" --data "size=5" https://lab.ndl.go.jp/dl/api/book/search
   ```

3. 版面の字面どおりに `example` を起こす。句読点は §2-2 の既存方針どおり、意味を変えない範囲で可読性のために補ってよい。
4. `example` を変えたら `cloze`（空欄の前後）と `translation` を必ず追随させる。`meta.dataVersion` は**据え置く**（上げると最終チェックBESTと途中位置が消える）。

## 11. 結論（2026-08-26）

§2-1で候補にした有朋堂文庫『源氏物語』を実際に開いて照合した結果、**本文系統がデータと一致しない**ことが分かり、源氏物語については**底本の特定を断念した**。

- 実証: kv15-169「ひがごと」の該当箇所（第4冊 p.316 / コマ163）は「母のはらから直々しくて、兄弟あるはなど、さやうの人は言ふ事あゝなるを思ひて」で、見出し語「ひがこと」が本文に無い。頭注が「下様の人はいふものなれば」と注しており、対応箇所であることは確認済み。
- 有朋堂文庫は流布本系、現在のデータは大島本系の校訂本文。同じ現象は kv15-180（なま女ばら→生女房）でも起きていた。
- 大島本系の公開活字翻刻は『校異源氏物語』全5巻（PID 3437686〜3437690、全巻公開）が唯一だが、総ひらがな・句読点なしの校異本文で、そのままでは学習例文にできない。

決定と根拠は [SOURCE_EDITIONS.md](SOURCE_EDITIONS.md)「源氏物語は底本を特定しない」と [AUTHORING_STANDARD.md](AUTHORING_STANDARD.md) §2-2 に反映済み。

**残件**: 枕草子の kv12-139 は底本（PID 1172432）を掲げているが本文が未照合。kv12-136 は後続確認で同資料p.4・canvas9の本文を照合済みである。伊勢物語は `kv04-042`・`kv12-135`・`kv12-140` が未解決のままである。

## 12. 追記（2026-08-31）
