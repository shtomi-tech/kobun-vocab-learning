## 1. 修正項目

### 1-1. 露出検査の粒度を調整する（優先度: 最高／論点A・再発防止）

現在の [check-data.mjs:100](../scripts/check-data.mjs:100) は、空欄の答え（`removed`）が `example` に2回以上現れると無条件でエラーにする。これが次の2種類を区別できていない。

- **本当の露出**: 答えそのものが別の場所にも出ていて、語義を知らずに正答できる（例: 旧 kv05-049「逆鱗」）。
- **誤検出**: 偶然の部分一致、またはその語の語法上の反復。

対応:

1. **1文字の空欄には適用しない。** `removed.length >= 2` を条件に加える。空欄が1文字の語は現在17語あり（`具`『文』`才』『院』『妹』『我』など）、他語の一部と偶然一致しやすい。
2. **ID例外表を設ける。** 既存の [headwordOwnedSuffixesById](../scripts/check-data.mjs:13) と同じ形で `answerRepeatAllowedById` を定義し、語法上の反復を明示的に許可する。

```js
const answerRepeatAllowedById = new Map([
  ["kv08-086", "かつ"], // かつ〜かつ〜: 反復自体がこの語の語法で、対句がないと語義を示せない。
]);
```

3. 例外に登録する場合は、**なぜ露出が許容されるのかをコメントで残す**（既存表と同じ運用）。

### 1-2. 原文を切った2語を復元する（優先度: 最高／論点B）

1-1 を先に入れたうえで、次の2語を段階2前の本文へ戻す。

**kv08-086「かつ」（`data/set-08.json`）** — 現状は語義が例文から読み取れない。

| 項目 | 現状 | 復元後 |
|---|---|---|
| `example` | よどみに浮かぶうたかたは、かつ消え… | よどみに浮かぶうたかたは、かつ消えかつ結びて、久しくとどまりたるためしなし。 |
| `cloze` | よどみに浮かぶうたかたは、（　）消え… | よどみに浮かぶうたかたは、（　）消えかつ結びて、久しくとどまりたるためしなし。 |
| `translation` | 淀みに浮かぶ水の泡は、一方では消え… | 淀みに浮かぶ水の泡は、一方では消え、一方では生まれて、長くとどまっている例はない。 |

`meanings` は「一方では。〜する一方で。」で、`かつ〜かつ〜` の対句があってはじめて語義が示せる。1-1 の例外表への登録が前提。

**kv02-020「みる」（`data/set-02.json`）** — 空欄の答えは「見」1文字で、例文中のもう1つの「見」は別語「見ゆ」の活用形「見え」の一部。答えの再出現ではない。

| 項目 | 現状 | 復元後 |
|---|---|---|
| `example` | …ものまめやかなりと… | …ものまめやかなりと見え、 |
| `cloze` | …ものまめやかなりと… | …ものまめやかなりと見え、 |
| `translation` | …誠実であるようで… | …誠実であるように見え、 |

こちらは 1-1 の「1文字は適用外」で通るため、例外表への登録は不要。

**復元は `git show HEAD:data/set-02.json` / `HEAD:data/set-08.json` の当該値をそのまま使う**（段階2で意図的に変えた本文ではないため）。

### 1-3. kv12-137「おとうと」の訳を訂正する（優先度: 高／論点C）

`data/set-12.json`、出典は古今和歌集巻十七・868番歌の詞書（底本『和歌三代集』上）。

- 現状の訳: 「妻の弟がいる人に、上着を贈るといって詠んで贈った。」
- 問題: 「めのおとうと」は通説では**「妻の妹」**。「持たりける人」も「妻の妹を妻に持っていた人（＝妹の夫）」と解される。訳が二重にずれている。
- 対応: 底本の当該箇所と、可能なら注釈を確認したうえで「妻の妹を妻としていた人に、上着を贈るといって詠んで贈った。」の趣旨へ訂正する。
- 注意: `example` / `cloze` は変えない（本文は正しい）。`meanings`（弟または妹。年下の兄弟姉妹。）も変えない。
- **確認が取れない場合**は訳を断定せず、「妻の妹（おとうと）を持っていた人に」のように原語を残した形にする。学習データでは不確かな解釈を断定しない（AGENTS.md）。

### 1-4. 軽微な不整合（優先度: 低）

- [WAKA_PHASE2_PLAN.md:62](WAKA_PHASE2_PLAN.md:62) のWikisource行に「23語」が残っている。他は24語へ訂正済みなので揃える。
- kv04-047「ぎょうけい」の訳「宮々や殿上人たち」。「とのばら」は殿方・貴人たちの意で、殿上人とは限らない。底本で確認のうえ「殿方たち」等へ改める。
